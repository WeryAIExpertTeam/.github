# WeryAI

We build AI tools for creative work and small, practical tools for the browser.

- [Wery — your AI expert team for creative work](https://www.wery.ai/?utm_source=github): image, video, music and writing tools in one workspace.
- [WeryAI online image tools](https://www.weryai.com/?utm_source=github): background removal, upscaling and other image workflows.

## Open source

### [WeryAI Image Toolkit](https://github.com/WeryAIExpertTeam/browser-image-toolkit)

Five local browser tools for collage, compression (including HEIC conversion), grid cropping, before/after videos and cover images, plus an optional link to online background removal. No image uploads for local editing. English and Chinese UI. MIT project code; third-party licenses apply separately.

**[Try the toolkit →](https://weryaiexpertteam.github.io/browser-image-toolkit/)**
